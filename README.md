プロジェクト名：MatchEigo　（視覚的な英語学習）

コンセプト：MatchEigoは全ての人に楽しくゲーム感覚で勉強！をコンセプトに、私のバックグラウンド（長期海外生活）を生かし日本語、英語を学びたい全ての人たちのためにエンジニアの技術を駆使し、私にしかできないオリジナルの製品を作りたいと思ったのがきっかけです。
　　　　　　いかに勉強を楽しく気軽に出来るかを目標に、絵文字という馴染みのある物を使い、視覚的に勉強できるようにしました。

ターゲットユーザー：子供から親、TOEIC学習者。家族で楽しんで勉強して頂きたい。

技術：
| カテゴリ        | 使用技術                                                                 |
|----------------|-------------------------------------------------------------------------|
| 開発環境  | Xcode 15, Swift 5.9,　UIKit |
| アーキテクチャ | MVC  |
| データ管理 | RealSwift（合計時間、スコア、ID、日付）、Firebase Firestore (絵文字、英単語、日本語単語クラウド同期)  |
| ライブラリ | RealmSwift,FirebaseFirestore,Lottie　|

Dependencies: Swift pakage manager
>Lottie：アニメーション
>RealmSwift：データ管理
>FirebaseFires：ゲームデータ管理

機能：
＞絵文字マッチ：初学者や小さいお子さんにアイフォン絵文字を使った視覚的学習 - 絵文字と意味が繋がる英単語をタップアンドマッチ
＞TOEICマッチ（スコア 0-350）：自身のレベルに合わせてTOEICの単語学習-よく出る単語をレベルに合わせて勉強、タップアンドマッチ
＞タイマー；1プレイにかかった時間とユーザーの過去のベストタイムを結果画面に表示
＞採点；間違えた数と正解数によって採点
＞モチベーションコメント：点数によってモチベーションコメントが変動、結果を応援
＞英語表示；日常的に使われる簡単な英語を見て学んで慣れていく、フレンドリー設定

ルール：
＞4つのマッチングカード
＞5ラウンド1プレイ
＞マッチしなかった場合マイナス1点
＞全てのカードがマッチして次のラウンド

リアルタイムコンテンツ管理：
Firestoreを使用し、以下のゲームデータを動的に管理：アプリの再ダウンロード不要でゲームデータ（絵文字・単語）を更新可能にし、ユーザー体験と運用効率を改善。
＞単語データ: 英語/日本語ペア  
＞絵文字: サーバー側で即時更新可能  
＞管理画面: 非エンジニアでもコンテンツ編集可能  

利点：
✅ アプリ更新不要でコンテンツ変更可能  
✅ オフライン時もデータ利用可能  
✅ 多言語対応が容易
